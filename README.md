# 강동 블로그 → 유튜브 제작기 v1

## 이번 버전에서 되는 것
- 네이버 블로그 URL 입력
- 네이버 글 자동 추출 시도
- 자동 추출 실패 시 본문/사진 URL 직접 입력 가능
- OpenAI로 유튜브 제목, 썸네일 문구, 3/5/7분 대본, 장면 구성, 설명란, 해시태그 생성
- TXT / JSON 다운로드

## 아직 안 되는 것
- MP4 자동 렌더링
- AI 음성
- 자동 자막 영상 합성
- 유튜브 자동 업로드

이 기능들은 v2에서 붙이는 순서가 좋습니다.

## Vercel 배포
1. 이 폴더를 GitHub 새 저장소에 업로드
2. Vercel에서 저장소 Import
3. Vercel 프로젝트 > Settings > Environment Variables
4. `OPENAI_API_KEY` 추가
5. 선택: `OPENAI_MODEL=gpt-6-luna`
6. Redeploy

OpenAI 키는 절대로 index.html에 직접 넣지 마세요. API 키는 서버 환경변수로만 보관합니다.

## 사용
1. 블로그 URL 입력
2. `블로그 읽기`
3. 내용 확인
4. `유튜브 초안 만들기`
5. 결과 복사 또는 TXT 저장

## 네이버 관련
네이버가 서버 접근을 막는 경우가 있어 자동 추출이 실패할 수 있습니다. 이때 본문을 직접 붙여넣으면 AI 생성 기능은 그대로 사용할 수 있습니다. 다음 버전에서는 브라우저 자동화 방식으로 수집 안정성을 높일 수 있습니다.
