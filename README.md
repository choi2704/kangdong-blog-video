# 강동 블로그 → 유튜브 제작기 v2

## v2에서 추가된 기능
- 네이버 블로그 사진 자동 수집 보강
- 수집한 사진을 화면에서 썸네일로 확인
- 사용할 사진 전체 선택 / 해제 / 개별 선택
- Naver 이미지 핫링크 문제를 피하기 위한 안전한 이미지 프록시
- OpenAI Responses API에 글 + 선택한 사진을 함께 전달
- AI가 실제 사진을 보고 장면별 사진 번호를 자동 배치
- 각 장면에서 선택된 사진 미리보기 + 선택 이유 표시
- 대본에서 "블로그 글에서 확인되지 않음" 반복을 줄이고 확인 필요 정보는 별도 영역에 정리

## 덮어쓸 파일
GitHub `kangdong-blog-video` 저장소에서 아래 파일들을 그대로 덮어쓰면 됩니다.

- `index.html`
- `api/extract.js`
- `api/generate.js`
- `api/image.js` (새 파일)
- `package.json`

Vercel 환경변수 `OPENAI_API_KEY`는 그대로 사용합니다.

## 배포
1. 이 ZIP을 풀기
2. GitHub 저장소에서 위 파일들을 덮어쓰기/추가
3. Commit changes
4. Vercel 자동 배포 완료 대기
5. `https://kangdong-blog-video.vercel.app/` 에서 테스트

## 테스트 순서
1. 블로그 주소 입력
2. `블로그 읽기`
3. 사진 썸네일이 뜨는지 확인
4. 필요 없는 사진 체크 해제
5. `초안 + 사진 배치`
6. 장면별로 사진 번호/썸네일이 배치되는지 확인
