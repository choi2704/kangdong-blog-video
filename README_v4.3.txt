# 강동 블로그 → 유튜브 제작기 v4.3

## 변경사항

### 1. 목소리 더 자연스럽게
- 기본 음성 Marin
- 기본 속도 0.97
- 목소리 느낌 선택:
  - 자연스럽게 대화하듯
  - 따뜻하고 친근하게
  - 차분하고 신뢰감 있게
  - 밝고 경쾌하게
- TTS에 한국어 억양, 호흡, 문장 끝 변화, 과장되지 않은 설명톤 지시
- `목소리 미리듣기` 버튼 추가

### 2. 사진 전환 더 매끄럽게
- 고정 22% 전환 대신 장면 길이에 따라 약 0.45~0.75초 크로스페이드
- ease-in/ease-out 적용
- 다음 사진은 전환 중 고정된 시작 위치에서 서서히 등장
- 확대/이동도 직선이 아니라 부드러운 곡선 움직임

### 3. 우리가 직접 오프닝/마무리 추가
영상 만들기 영역에서:
- 오프닝/썸네일 이미지 또는 영상
- 마무리 이미지 또는 영상
을 PC에서 직접 선택할 수 있습니다.

선택하지 않으면 기존 자동 화면 사용:
- 오프닝: 제목 + 강동자바라
- 마무리: 강동자바라 + 1577-6084

업로드 영상은 화면만 사용하며 원본 영상 소리는 포함하지 않습니다.
