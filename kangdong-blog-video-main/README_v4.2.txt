# 강동 블로그 → 유튜브 제작기 v4.2

## 새 기능
대본 생성 후 영상 제작 전에 직접 수정할 수 있습니다.

### 장면별 수정
각 장면마다:
- 장면 제목
- AI 음성 내레이션
- 화면 자막

을 직접 수정할 수 있습니다.

`수정내용 반영`을 누르면 영상 제작에 적용됩니다.
영상 만들기를 눌러도 수정내용이 자동으로 한 번 더 반영됩니다.

### 자막과 내레이션을 다르게 사용
예:
내레이션:
"먼저 돌출난간대가 어떤 제품인지부터 살펴보겠습니다. 이름처럼 벽면 바깥쪽으로 일정 폭만큼 튀어나온 구조입니다."

자막:
"벽면 바깥으로 돌출된 난간 구조"

처럼 짧게 수정할 수 있습니다.

자막 칸을 비우면 내레이션 문장을 자동으로 잘라 자막으로 사용합니다.

### 전체 내레이션
전체 내레이션도 직접 수정할 수 있습니다.
전체 내용을 크게 고친 경우:
`전체 내레이션을 장면별로 다시 나누기`
버튼으로 장면별 내레이션에 다시 배분할 수 있습니다.

## 추천 작업 순서
1. 블로그 읽기
2. 사진 직접 선택
3. 초안 + 사진 배치
4. 장면별 내레이션/자막 수정
5. 수정내용 반영
6. 영상 만들기
7. 미리보기
8. 다운로드
