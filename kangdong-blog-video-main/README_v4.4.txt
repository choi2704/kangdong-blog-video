# 강동 블로그 → 유튜브 제작기 v4.4

## 이번 수정

### 장면 순서 변경
각 장면 오른쪽에:
- ↑ 위로
- ↓ 아래로
버튼을 추가했습니다.

버튼을 누르면 장면 자체가 이동하고,
내레이션/자막/추가 이미지·영상도 장면과 함께 이동합니다.

### 장면 추가/삭제
- 장면 구성 상단: `+ 장면 추가`
- 각 장면: `삭제`

새 장면을 추가해 별도 안내 장면을 만들 수도 있습니다.

### 각 장면에 이미지·영상 직접 추가
각 장면에:
`이 장면에 이미지·영상 추가`

파일 선택창을 넣었습니다.
여러 장을 한 번에 선택할 수 있습니다.

추가 가능한 파일:
- JPG / PNG / WebP 등 이미지
- MP4 / WebM 등 브라우저가 재생 가능한 영상

추가한 파일은 블로그 사진과 함께 해당 장면 안에서 순서대로 사용합니다.
추가 영상은 소리 없이 화면만 사용합니다.

### 장면별 파일 삭제
추가 미디어 썸네일의 × 버튼으로 개별 제거할 수 있습니다.

## 추천 활용
예:
장면 1: 직접 만든 썸네일 이미지
장면 2: 블로그 전체 제품사진
장면 3: 휴대폰으로 찍은 제작 영상 추가
장면 4: 손잡이 근접사진
장면 5: 설치 완료 영상
장면 6: 직접 만든 상담 안내 이미지
