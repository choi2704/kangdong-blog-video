# 강동 블로그 → 유튜브 제작기 v3

## 이번 단계
사진 60장을 가져온 뒤 사람이 하나씩 고르지 않아도
`AI 사진 자동선택` 버튼으로 대표 사진 약 18장을 자동 선택합니다.

AI가 우선 제외하는 것:
- 거의 같은 중복 사진
- 로고/아이콘
- 캡처 화면
- 글자 위주의 이미지
- 너무 흐린 사진

AI가 우선 선택하는 것:
- 제품 전체 모습
- 설치 완료 모습
- 구조 설명에 좋은 근접 사진
- 부품/모서리/받침 등 디테일
- 서로 다른 각도의 대표 사진

## 적용
ZIP 압축을 풀어 GitHub `kangdong-blog-video` 저장소에 같은 구조로 덮어쓰기합니다.

추가되는 파일:
- api/select-images.js

수정되는 파일:
- index.html

기존 파일:
- api/extract.js
- api/generate.js
- api/image.js
- package.json

Commit changes 후 Vercel 자동 배포가 끝나면 화면 상단에 `v3`가 표시됩니다.

## 사용 순서
1. 블로그 읽기
2. 사진 미리보기 확인
3. `AI 사진 자동선택`
4. AI 추천 약 18장 확인
5. 필요하면 체크 직접 수정
6. `초안 + 사진 배치`
